# Cap Civique

Petit site statique pour s'entraîner au test civique français. Les 10 séries et leurs corrigés proviennent du document `Test.docx` fourni pour ce projet.

## Lancer en local

Ouvrir `index.html` via un serveur statique (le chargement du fichier JSON nécessite HTTP) :

```sh
python -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Publication

Le site est prévu pour GitHub Pages. Il fonctionne sans compte candidat et ne collecte ni nom ni résultat. Les réponses restent dans la session de la page.
